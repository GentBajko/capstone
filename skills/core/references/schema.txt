# The output schema: one record per kind of file capstone writes under a
# docs area, in the machine-readable form the gate can read without a
# model.
#
# skills/core/scripts/map-check.sh reads this file at runtime and keeps
# no copy of it. references/topics.md and the protocol files under
# references/protocols/ carry the prose a model follows while writing a
# page; lint-sync checks 15, 20 and 21 assert that the prose and this
# file still say the same thing, so changing one alone turns the lint
# red.
#
# A change here reaches pages already on disk the ordinary way. Their
# `capstone_version` now sits below the plugin's, part 1 calls them
# "written by an older capstone", and the next `map` run rewrites them
# against the current template.
#
# Format. One record per output type. Records are separated by a blank
# line, fields are one per line, and a line whose first character is `#`
# is a comment. The fields:
#
#   type      <id>                  the record's name, unique
#   match     <glob>                a path relative to the docs dir, as a
#                                   shell glob; a record may carry more
#                                   than one
#   keys      <k> <k> ...           frontmatter keys required inside git
#   keys!     <k> <k> ...           frontmatter keys required always
#   opt       <k> <k> ...           keys from `keys` that a page carrying
#                                   no `paths_covered` does not owe
#   head      <H>|<H>|...           required `## ` headings, in this order
#   table     <Heading>:<C>|<C>     the first table under `## <Heading>`
#                                   must carry these columns
#   subtable  <Heading>:<n>:<C>|<C> every heading at level `<n>` under
#                                   `## <Heading>` must carry a table
#                                   with these columns
#   from      <file>|<section>      the protocol section `head` was
#                                   copied from; lint check 20 reads it
#
# Matching. The first `match` glob that fits the path decides the
# record, and records are tried in file order, so specific patterns sit
# above general ones. The last record is a catch-all: every markdown
# page under a docs area owes `generated_date` even when nothing more
# specific claims it. The resolved index file is looked up by the `index`
# record whatever `index_file` names it, so a docs area that renames its
# index still gets the index rules rather than a chapter's.
#
# Headings. `head` is an ordered sequence. A heading that is not there is
# the finding `## <H>`. A heading that sits ahead of one that should
# precede it is `## <H> out of order (before ## <Prev>)`. Extra `## `
# headings are never a finding, so a chapter may carry sections beyond
# the ones the template names.
#
# Tables. The heading and the level are split off a `table` or
# `subtable` value at its first colon, so a heading holding a colon
# cannot be named by either field; no template heading holds one.
# Columns are matched by lowercased header name, never by position, and
# extra columns are allowed. A missing column is the finding
# `table <Heading> missing <Column>`. A heading whose `head`
# entry is itself absent reports the heading alone and no columns, so one
# gap is one finding. `table` says nothing about a section that carries
# no table: topics.md tells a deep-dive to write "None found" plus where
# it looked, so an empty section is the sanctioned answer. `subtable` is
# strict the other way, because topics.md gives a `### <Entity>` section
# no such out - it holds a field table or it holds nothing anyone can
# read. All of these land in part 8's missing-headings column and count
# toward the stale verdict.
#
# Waivers. `mode: prescriptive` waives `keys` outright: a design written
# before the code has no commit to stamp. Outside git `keys` is waived
# for the same reason, and `keys!` is owed under both. `opt` waives its
# keys on a page with no `paths_covered`, which is how an interview's
# output and the same file written by extraction are told apart.
